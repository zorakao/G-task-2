# 花漾生活前台重新設計

## User Story
以 Pencil MCP 交付花卉電商所有前台頁面的可編輯設計，搭配 frontend-design skill，涵蓋桌面與手機購物流程。

## Spec
- 頁面：首頁／商品列表、商品詳情、購物車、結帳、登入、註冊分頁、我的訂單、訂單詳情、404。
- 關鍵狀態：空購物車、空訂單、商品售完、載入、欄位錯誤、移除確認、付款查詢／成功／失敗。
- 維持品牌「花漾生活」，繁體中文，以現有商品與價格設計。
- 設計交付；本次不變更 EJS、Vue 或 API 行為。

## Design plan
- 六個基礎色：霧白 #FAFBF9、花莖綠 #233F35、紫丁香 #79618D、花瓣紫 #E4DCEC、冷霧 #F3F0F8、葉灰 #536258。
- 輔助線色 #DDE3DD；成功、錯誤、等待狀態皆搭配文字與圖示。
- 字體：Noto Serif TC 用於品牌與主標題；Noto Sans TC 用於內文、價格、導覽及表單。尺寸 12/14/16/20/24/32/48/64，內文行高 1.6。
- 版面：1440px 桌面，內容 1280px；390px 手機、兩側 20px；8px 間距基準。內容左對齊；只有登入及空狀態等單一任務區域置中。

```text
首頁： [品牌 / 商品 / 訂單 / 登入 / 購物車]
       [大標題與選花按鈕 | 具有真實花材質感的大照片]
       [商品標題與件數]
       [花材照片][花材照片][花材照片]
       [名稱/價格/加入購物車]
交易： [導覽 / 購物進度]
       [商品明細或收件表單       | 金額 / 主要行動]
手機： [品牌 / 選單 / 購物車]
       [文案 → 照片 → 商品；表單 → 摘要 → 主要行動]
```

## Brief review
- 捨棄原本粉紅色膠囊按鈕與每區一張圓角卡片的形式，改為由花材照片主導、冷紫背景與花莖綠操作色。
- 避免奶油底／陶土色、全大寫裝飾標籤及報紙式密集分欄。
- 首頁的視覺重點集中在花束攝影與大字，其餘流程以清楚的表單、金額和動作優先。
- 不加入沒有 API 支援的搜尋、分類、優惠碼、收件日期或物流追蹤。
- 運費依現有購物車展示（滿 NT$500 免運），示例訂單皆高於免運門檻；實作前仍須確認後端運費計算。
