# 商品順序對齊設計稿

## User Story
商品被刪除後還原，仍應顯示在設計稿指定的位置。前台與後台列表及分頁使用相同順序。

## Spec
- 依首頁設計稿：粉色玫瑰、白色百合、向日葵、紫色鬱金香、乾燥花圈、多肉盆、紅玫瑰、季節鮮花訂閱。
- 前後台在 SQL 分頁前套用同一排序規則；其他商品接在設計商品後，按建立時間倒序、商品編號正序保持穩定。
- 保留商品資料、庫存、既有訂單及 API envelope，不調整資料庫結構。
